How I Build with the Model Context Protocol (MCP)

Instead of brittle prompts and hallucinated actions, I architect system boundaries around Anthropic's open MCP standard with strict JSON-RPC schemas and verified execution.

mcp-server-business-operations — stdio
JSON-RPC 2.0 Connected
// 1. Claude calls typed MCP tool with validated arguments
> client.callTool("accounting.list_overdue_invoices", { minDaysOverdue: 14, includeClientDetails: true })
// 2. MCP Server schema verification (Zod) + Transactional DB Lookup
✓ Schema verified against ZodType<OverdueInvoicesInput>
✓ Executed SQLite prepared query: SELECT * FROM invoices WHERE status = 'overdue' AND due_date < date('now', '-14 days')
// 3. Structured result returned to Claude context
{
  "content": [

      "type": "text",

  "_auditId": "evt_9f8e21a8d01b"
}

Strict Schema Contracts

Every MCP tool uses Zod schemas with complete parameter validation, redacting secrets and ensuring agents cannot invoke undefined operations.

Human-In-The-Loop Staging

Destructive write actions generate cryptographically signed previews in pending state, requiring explicit manager confirmation before database commits.

Immutable Audit Logging

Every read, tool invocation, approved mutation, and error is captured into structured event logs for compliance, analytics, and replayability.

Design Philosophy

Software Engineering Rigor Over "Prompt Magic".

Many AI demos rely on unverified text generation that fails in production. My engineering approach treats LLMs as cognitive microservices integrated into deterministic, testable software architectures.

✓
Deterministic Intent & Fallbacks: If a user request does not match an authorized tool schema, the system explains supported operations instead of hallucinating fake business records.
✓
State Machines Over Chat Transcripts: Complex multi-step workflows (such as invoice approvals or KYC onboarding) are tracked as database-backed state machines, not volatile chat context.
✓
End-to-End Testability: Comprehensive unit and integration test suites covering tool validation, mock agent intent resolution, access controls, and replayable audit logs.
